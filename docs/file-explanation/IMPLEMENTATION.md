## 第一阶段范围

复用Tauri、reqwest、serde、llama-cpp-2和React。文件列表点击后先读本机证据，展示固定词表生成的搜索词；用户选择本机生成或联网生成。云端模式明确显示完整路径、线索和问题会发给所选模型服务。无需重训，不改扫描器，不新增删除或迁移操作。

- 本机证据：重新读取属性；相邻config.json仅取有限model_type字段；模型索引检查weight_map是否引用当前分片；最多六层父目录检查pyvenv.cfg/conda-meta/history标记。配置读取最多64KiB；不加载模型/脚本，不递归读取个人文档。拒绝网络共享、设备路径、目录跳转与重解析路径。
- 网络证据：只发送程序内置的通用软件/格式词，不发送实际文件名、用户名、仓库名、配置值或追问。按软件限制官方资料域名（GGUF限定ggml-org/llama.cpp仓库），保存至多三段原文、标题和URL。查询使用[官方Tavily Search接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)，include_answer=false；不使用生成摘要作为事实。
- 输出：归属用途、删除影响、恢复条件、处理建议；每项包含text/status/evidence_ids，另列unknowns。supported表示资料支持而非当前文件安全认证。本地使用GBNF约束；云端服务差异由严格JSON反序列化与语义边界检查兜底，不默默显示不合格的自由文本。
- 校验：不存在的证据、空字段、过长输出、未知字段、未正常结束回答都会报错。恢复来源/备份未实际核验，因此禁止recovery=supported。引用有效不证明语义正确，模型仍可能误读资料。
- 文件变化：生成前后重采集并比对属性和证据指纹；它不是完整内容哈希或原子快照，不能用于批准删除。
- 异常：搜索失败明确显示，并仅依据本机线索继续；预览失败和模型失败显示错误。切换文件或关闭窗口后忽略旧结果。关闭不强杀正在执行的本地推理。
- 交互：四项解释、原始依据、检查范围、查询词、未知项、打开所在位置；追问重新核对证据并更新四项解释。追问不保留长对话上下文，避免旧回答变成事实。

### 本地体验步骤

在本分支工作目录的frontend中执行npm run tauri dev（或npx tauri dev），按原应用方式选择模型服务；本地模式需先加载GGUF。扫描后点击文件，先看本机依据，再选择生成或配置Tavily后联网分析。测试时只读查看，不能把模型文本当作删除许可。
