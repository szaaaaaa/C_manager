# 本地联网搜索：当前规则

## 通用入口（2026-10-11）

所有文件名都能生成中文搜索词，不维护扩展名或软件类型白名单。普通文件默认为“文件名 文件用途 删除影响”；识别到父目录中相关软件的产品名时，分成两条可编辑查询：“软件名 功能 用途”和“组件名 文件名 文件用途 删除影响”。产品名、模型标识保留原文，不硬编码品牌翻译。DDGS使用cn-zh地区设置。只有点击联网分析，才发送输入框中的每行文本；最多两行，不悄悄添加其他查询。

本机分析使用完整目录层级、相邻模型配置中的model_type/architectures/_name_or_path，以及最多六层父目录内可执行文件的版本资源（产品名、公司、描述）。不启动这些程序、不读取模型权重。每层最多枚举128项、检查4个EXE，总共最多12个；单个EXE上限64MiB，版本资源上限64KiB。超过范围或没有元数据时仍可搜索，但不会因此确认归属。父目录产品声明只提供安装线索，不是签名验证、运行依赖或训练者证明。

自动查询可带安装位置中的软件和组件名称；Users下仅从AppData的厂商/软件层提取名称，私人项目目录不自动拼入查询，不发送整条路径。版本资源中的产品名称仍可能包含私人命名，用户可在预览中修改。云端模型模式仍按界面提示发送完整本机证据给用户配置的模型服务。

不再自动追加 site:，不再限定微软、Hugging Face 等网站，不再排除社区问答或其他 GitHub 仓库。用户可自行在查询中加限定条件。检索结果先参考本机父目录与网页的共有词（较长的组件词优先），再按查询词匹配排序，读取前两条；目录信息只用于本机排序，不发给搜索网站。正文参考相同目录上下文，保留相关段落及相邻步骤、条件，不再使用 WSL/模型文件专用词表。读取正文后再次排序；已有目录匹配资料时，不再混入完全没有目录词匹配的页面。词匹配只是相关性线索，不是归属或删除安全认证。

流程：目录和产品线索 → 中文查询预览 → DDGS/Daedra（或配置的Tavily）→ 网页资料 → 结合本机目录、配置判断应用与用途 → 四项结构化解释。双查询各保留一条不同来源并重新编号，避免模型通用介绍挤掉应用功能资料；单条失败会明确显示，全部失败则报错。Bing广告跳转链接不作为用途资料。模型不自主规划额外查询。

## 保留的技术边界

搜索词总长1至300字，最多两行，除换行外不含控制字符。网页只读 HTTP(S) 的标准端口，无 URL 凭据；DNS 地址必须属于公网，并固定连接已检查的地址，不跟随重定向，避免访问本机、内网或地址重绑定。每条查询最多读取两页，双查询最多四页候选、最终合并最多两项来源；每页连接超时10秒、读取上限1MiB；正文摘录限制1800 UTF-8字节，避免挤满小模型上下文。搜索与正文进程各有30秒上限。

Daedra 无有效结果时明确用 DDGS 补搜；都失败则报告失败，不生成冒充联网结果的本机解释。模型未引用网络来源时报告未通过检查。搜索入口开放不代表互联网一定有资料，也不代表返回资料可靠。
