## 本次范围与边界

这是规则的用途标签层，不是联想清理执行器：不复制独占打开探测、运行进程跳过、删除失败集合或大文件保护排除，不隐藏Windows/Program Files下的扫描结果。

1358条普通 file 子规则用于匹配；15条 registry、1条 recycle、1条 WPSBackupfile 需要专用处理器，本版保留数据但不按普通文件路径执行。6个 INSTALLPATH 路径依赖联想软件库存中的安装位置，目前没有该库存，明确跳过这些未解析路径；同规则中的其他可解析路径仍有效。不会把缺失安装根替换成任意目录。escape 记录为 requires_idle，不声称已经检查运行状态。此范围不支持将全部规则命中结果当作安全可删判定。
